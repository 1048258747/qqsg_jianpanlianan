# QQ三国键盘连按工具

一个为《QQ三国》游戏设计的**键盘连按 + 流程自动化**辅助工具。可锁定目标游戏窗口，按设定序列自动按键，也可通过图像识别执行多步骤自动化流程。

> ⚠️ 自动按键类辅助工具可能违反部分游戏的用户协议，请自行确认使用环境后再使用。仅供个人娱乐用途。

## 功能特性

### 键盘连按
- **自动锁定窗口** — 按标题正则匹配并锁定 QQ三国窗口，支持多窗口选择
- **自定义按键序列** — 多个按键按顺序循环执行（如 `A,B,C`）
- **灵活时间控制** — 可调按键间隔、按键时长
- **随机抖动** — 在预设值附近随机波动，模拟人工操作、降低可识别度
- **全局快捷键** — 默认 F8，在游戏全屏/后台也能一键开始 / 停止连按（可自定义）

### 流程编辑器
- **多步骤流程** — 键盘按键、延时、鼠标点击、图像识别等步骤自由编排
- **图像识别** — OpenCV 模板匹配（支持中文路径），识别到目标后执行动作
- **条件判断与循环** — 支持条件分支和循环控制的复杂自动化脚本

### 整体
- **现代深色 UI** — CustomTkinter 实现，侧边栏导航 + 卡片式布局
- **系统托盘** — 隐藏到右下角托盘，不影响游戏
- **输入法自动切换** — 自动切到英文输入法，避免中文干扰
- **自动管理员权限** — 与游戏同权限，确保快捷键在游戏前台可用
- **三国风格应用图标** — exe / 窗口 / 托盘图标统一

## 技术栈

- **语言与 GUI**：Python 3.7+，CustomTkinter（深色主题）
- **系统 API**：ctypes / pywin32（PostMessage 模拟按键、RegisterHotKey 全局热键）
- **图像识别**：OpenCV、numpy、pyautogui
- **系统托盘**：pystray + Pillow

## 环境要求

- Windows 10 / 11
- Python 3.7+（推荐 3.12）

```bash

pip install -r requirements.txt

> 首次启动会弹出 UAC 管理员授权，点"是"即可。以管理员运行能让快捷键在同样以管理员运行的游戏内生效。

## 使用方法

### 1. 键盘连按
1. 启动游戏，点击 **查找窗口** 搜索 QQ三国窗口，选择并 **锁定窗口**
2. 在 **按键序列** 输入框填写要连按的按键，用逗号分隔，如 `A` 或 `A,B,C`（留空则每次自行填写）
3. 设置 **按键间隔**（毫秒）与 **按键时长**（毫秒）
4. 点击 **开始连按**，之后点击 **停止连按** 结束

### 2. 全局快捷键
- 默认快捷键为 **F8**，按一下开始连按，再按一下停止
- 在"键盘连按"页的"控制"卡片中可下拉更换快捷键（F6–F12 / HOME / END / INSERT / DELETE），点击 **应用** 生效
- 侧边栏会同步显示当前快捷键与运行状态

### 3. 流程编辑器
1. 切换到 **流程编辑器** 页
2. 通过 **添加步骤** 编排流程（按键、延时、鼠标点击、图像识别等）
3. 为图像识别步骤选择模板图片，并设定匹配区域与置信度
4. 点击 **执行流程** 运行，试点步骤可 **停止** 中断

### 4. 隐藏到托盘
- 点击 **隐藏到托盘**，窗口缩到右下角托盘图标
- 右键托盘图标可选择 **显示窗口 / 退出程序**

## 打包为 exe

```

## 常见问题

**Q：按键没有反应？**
A：请以管理员身份运行本工具，并确认锁定了正确的游戏窗口。

**Q：找不到游戏窗口？**
A：确认游戏已启动，且窗口标题包含"QQ三国"字样。

**Q：为什么要在游戏里按 F8 没反应？**
A：通常是权限不同。游戏以管理员运行时，本工具也需以管理员运行（程序会自动提权重启）。若快捷键提示被占用，请到"控制"卡片换一个键再应用。

**Q：中文输入法导致按键无效？**
A：勾选"自动切换英文输入法"，或手动切换到英文输入法。
