# QQ三国键盘连按工具

一个为游戏《QQ三国》设计的键盘连按辅助工具，可以自动在游戏窗口中模拟按键操作。

## 功能特性

- **自动窗口锁定** - 自动检测并锁定QQ三国游戏窗口
- **自定义按键序列** - 支持设置多个按键，按顺序循环执行
- **灵活的时间控制** - 可调整按键间隔和按键时长
- **多窗口支持** - 支持同时运行多个游戏窗口，可选择目标窗口
- **系统托盘** - 隐藏到右下角托盘图标，不影响游戏界面
- **输入法自动切换** - 自动切换到英文输入法，避免中文输入干扰

## 环境要求

- Windows 操作系统
- Python 3.7+
- 需要安装以下依赖：
  - pywin32
  - pystray
  - pillow

## 安装步骤

1. 确保已安装Python 3.7或更高版本

2. 安装依赖包：
   ```bash
   pip install -r requirements.txt
   ```

3. 运行程序：
   ```bash
   python main.py
   ```

## 使用方法

### 1. 查找游戏窗口
- 默认窗口标题模式为 `QQ三国.*线`
- 点击"查找窗口"按钮搜索游戏窗口
- 如果只找到一个窗口，会自动锁定；如果找到多个，需要手动选择

### 2. 锁定窗口
- 从下拉列表中选择目标窗口
- 点击"锁定窗口"按钮锁定该窗口

### 3. 设置连按参数
- **按键序列**：输入要连按的按键，用逗号分隔，例如：`A` 或 `A,B,C`
- **按键间隔**：每次按键之间等待的时间（毫秒），默认500ms
- **按键时长**：按键按下的持续时间（毫秒），默认50ms

### 4. 开始/停止连按
- 设置好参数后，点击"开始连按"开始自动按键
- 点击"停止连按"停止按键

### 5. 隐藏到托盘
- 点击"隐藏到托盘"按钮，窗口会隐藏到右下角
- 点击右下角的托盘图标可以恢复窗口显示
- 关闭程序时也可以选择隐藏到托盘而非退出

## 注意事项

1. **管理员权限**：某些游戏可能需要以管理员身份运行才能正确接收按键
2. **输入法**：建议关闭中文输入法或勾选"自动切换英文输入法"选项
3. **窗口焦点**：确保游戏窗口在前台时连按功能正常工作

## 按键支持

支持以下按键：
- 字母键：A-Z
- 数字键：0-9
- 功能键：F1-F12
- 控制键：SPACE, ENTER, TAB, ESC, BACKSPACE, DELETE, INSERT, HOME, END
- 方向键：UP, DOWN, LEFT, RIGHT
- 小键盘：NUMPAD0-NUMPAD9

## 常见问题

**Q: 按键没有反应**
A: 请确保以管理员身份运行程序，并锁定正确的游戏窗口

**Q: 找不到游戏窗口**
A: 请确保QQ三国游戏已启动，窗口标题包含"QQ三国"

**Q: 中文输入法导致按键无效**
A: 勾选"自动切换英文输入法"选项，或手动切换到英文输入法
